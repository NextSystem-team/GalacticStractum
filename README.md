# Galactic Stractum

> *A game about exploring vast space in search of asteroids to extract and obtain unique resources from these celestial bodies. 
Made for the FIAP Global Solution - Space Connect.* 

## About the Project
**Galactic Stractum** is a space-themed game based on mining asteroids, extracting their resources, and selling them to meet quotas and avoid your company's bankruptcy. 

## Key Mechanics & Features
*  **Turn and accelerate:** Accelerate with the W key and use the A and D keys to turn and maneuver.
*  **Random map generator:** Every match has a different pattern of asteroids!.
*  **Explore the unknown of space:** "Dig" through the darkness of the unknown and discover asteroids as you move or use tools.
*  **Dynamic prices:** Prices fluctuate each round, so sell your resources at the right time! But be careful not to saturate the market.

## Controls
* **W, A and D** - Accelerate and turn keys.
* **Right Click** - Dequip the current tool.
* **Esc** - Pause the stage or close windows.

## 🛠️ Built With
* **[Unity](https://unity.com/)** - Game Engine
* **C#** - Programming Language
